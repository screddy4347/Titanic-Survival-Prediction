# Titanic Survival Prediction

## Overview

This project is a simple **machine learning analysis** using the famous **Titanic dataset**. The goal is to predict whether a passenger survived or not based on available features.

---

## Dataset

* Dataset: Titanic Dataset
* File used inside the notebook
* Type: Classification problem

---

## Tools & Libraries

* Python
* pandas
* numpy
* matplotlib / seaborn
* scikit-learn
* Jupyter Notebook

---

## Steps Performed

1. Loaded the dataset
2. Explored the data (rows, columns, data types)
3. Cleaned missing values
4. Encoded categorical features
5. Split data into training and testing sets
6. Trained a machine learning model
7. Evaluated model accuracy
